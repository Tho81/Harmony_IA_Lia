# Public / private boundary

This repository is intentionally isolated from the private HARMONY IA LÍA development environment.

## Allowed in this public repository

- physical-embodiment thesis;
- high-level five-layer sensorimotor envelope;
- standard robotics equations and control relationships;
- public-source technology comparisons;
- academic/industrial sources;
- design questions, validation criteria and interoperability discussion;
- public brand imagery already approved for publication.

## Never publish here

- credentials, API keys, tokens, `.env` files or secrets;
- personal/private memory or conversation data;
- source code from private systems;
- private prompts or tool policies;
- unpublished models, datasets or voice sources;
- local file paths or network/infrastructure topology;
- private repository names, links, deploy keys, webhooks or GitHub App configuration;
- internal milestones, implementation details or proprietary embodiment methodology;
- medical/patient or other personal data.

## Isolation rule

This repository must contain **no submodules, CI credentials, deploy keys, package registries, Actions secrets or automation that grants access to a private repository**.

Public discussion is informational only. Access requests to private project systems are out of scope.
