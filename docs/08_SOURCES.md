# 08 · Sources and public technical references

## Primary industrial sources

1. **OpenAI — Agents API**  
   https://openai.com/index/introducing-the-agents-api/  
   Public documentation on long-running agents, tools, environments and orchestration.

2. **Tesla — AI & Robotics / Optimus**  
   https://www.tesla.com/AI  
   Public description of bipedal robotics problems including balance, navigation, perception and physical-world interaction.

3. **Unitree — G1**  
   https://www.unitree.com/g1/  
   Public specifications covering low-inertia PMSM joints, humanoid DoF, force-position hand control and optional tactile sensor arrays.

4. **ENGINEAI**  
   https://en.engineai.com.cn/  
   Public descriptions of PM01/SE01 and other embodied-intelligence platforms.

5. **Engineered Arts — Ameca**  
   https://engineeredarts.com/robots/ameca/  
   Public specifications and HRI material including 61 actuated movements, 27 DoF in head/facial features and expressive behavior.

6. **NVIDIA — Jetson Thor**  
   https://www.nvidia.com/en-us/autonomous-machines/embedded-systems/jetson-thor/  
   Current 2026 embedded physical-AI reference: up to 128 GB LPDDR5X on T5000, 64 GB on T4000, NVMe/PCIe support, multi-gigabit networking and 40–130 W module power envelope.
