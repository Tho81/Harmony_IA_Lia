# Contributing

This public repository is intended for **technical discussion of physical humanoid embodiment**, not for access to private project development.

Useful contributions include:

- peer-reviewed references on materials, e-skin, tactile sensing and HRI;
- measured material properties and trade-offs;
- public robot specifications with primary-source links;
- critique of the five-layer sensorimotor-envelope hypothesis;
- control/safety observations based on standard robotics practice;
- proposals for open interoperability boundaries between high-level AI and deterministic robot control;
- corrections to factual or bibliographic errors.

Please do **not** submit:

- credentials, secrets or personal data;
- proprietary content you do not have rights to share;
- reverse-engineered private project material;
- requests for private repository access;
- claims of partnership or endorsement by referenced companies;
- code copied from unrelated projects without a compatible license.

By contributing text, you agree that your contribution may be distributed under the repository's documentation license (CC BY-SA 4.0) unless explicitly agreed otherwise.
